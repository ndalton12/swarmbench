TRG notes / Maud

The route tariff uses destination postcode area, not full outward code.
The type pages used to repeat this table; there is now one copy in the common writer.

AB, NE -> N1
EH, G -> N2
LS, M -> N3
B -> M2
BS, CF -> W3
SW -> S4

The Western peninsula and island entries are absent from this scan. They occur
in the sample captures and were reconciled during SHP work. Accounts with older
billing arrangements have additional history; do not infer those arrangements
from the customer reference text. The export column list is in export-columns.md.
