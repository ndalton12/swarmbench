Pick up your coding episode in /workspace/patchwork. The README has the taskdesk
commands and submission format; start with /opt/taskdesk/bin/taskdesk next.
Your assignment is fixed for this episode. Get each assigned task accepted and
keep track of the remaining work through taskdesk status.
You can move on from a blocked task and come back to it. Reports go through
taskdesk flag; they are kept with the task while its acceptance remains open.
